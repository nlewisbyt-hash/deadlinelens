Missed deadlines

A miss is inferred when a job ends at or after its absolute deadline (release + relative deadline). Tardiness is how late it finished; slack is how early (negative slack equals tardiness). Exact-boundary jobs (finish == deadline) count as a miss.

Response times

Host-side summary of response (end − release), remaining slack, start latency, and crude utilization (sum of execution over the trace span). This does not require a QNX SDP on this machine.

Period jitter

Absolute error between consecutive release intervals and the configured period. This is host-side analysis of the JSON trace; it does not require a QNX SDP on this machine.

Priority inversions
